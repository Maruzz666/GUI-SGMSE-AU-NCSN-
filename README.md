# GUI-SGMSE-AU-NCSN-
Una interfaz grafica para la Red Neuronal SGMSE dedicada a procesamiento de audio. Añade el procesamiento por GPU y Hibrido (CPU y GPU),Interfaz Comada,ajuste de parametros,Seleccion de modelos,entre otros...

Limitaciones: 

-El procesamiento por GPU es MUY CARO en VRAM, Crece el uso rapidamente al aumentar la duracion del audio.
-en CPU es muy lento
-la calidad no puede ser la esperada
